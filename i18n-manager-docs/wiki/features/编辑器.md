# 编辑器

> 主编辑器页面（`/projects/[id]`）采用左右双栏布局，两侧均用 Monaco Editor 编辑 JSON。

## 布局

- **顶部工具栏**：项目标题、项目内译文搜索框、在线人数徽标、导入/导出按钮。
- **左右分栏**（antd `Splitter`，可拖拽）：主表 Schema（左栏）/ 多语言编辑器（右栏），各自独立工具条。
  - **默认比例**：Schema 40% / 多语言 60%。
  - **拖拽调整**：拖动分割条改变两栏宽度；各栏 `min 25% / max 75%` 保护可用宽度。
  - **持久化**：分栏比例存浏览器 `localStorage`（键 `i18n-manager:editor-split`，存左栏比例 0~1），**全局一份**、跨项目共享——它是浏览器本地工作区习惯，非项目数据（区别于「速查开关」这类跨用户协作状态）。
  - **双击分割条**：重置为默认 40/60。
  - 实现：`EditorSplitPane`（`src/components/project/EditorSplitPane.tsx`）受控模式 + `onResizeEnd` 才写 localStorage；`left`/`right` children 引用稳定，拖拽重渲染时编辑器子树（Monaco）免重建。
- **左栏**：主表 Schema 编辑——工具栏（添加键 + 格式化 + 保存状态/JSON 校验指示器）+ Monaco JSON。
- **右栏**：语言 Tab 栏（Ant Design Tabs）+ 当前语言译文 Monaco JSON。空态："暂无语言，请点击 '+' 按钮添加"。

## MonacoEditor 封装

- `'use client'`，`forwardRef` + `memo`，经 `next/dynamic` 动态导入（SSR 安全）。
- 暴露方法：`getValue`、`setValue`、`focus`、`find`、`formatDocument`、`getEditor`、`getCursorPosition`。
- **`setValue` 走最小编辑**：`computeMinimalEdit` + `model.pushEditOperations`，保留 undo 栈与折叠状态；不手动保存/恢复光标（决策 11）。
- 默认配置：JSON 语言、`vs-dark`、`automaticLayout`、`formatOnPaste`、`folding`、`bracketPairColorization` 等。
- **`find.addExtraSpaceOnTop: false`**（有意偏离上游默认 `true`，2026-08-20）：查找框纯悬浮右上角（overlay widget），不插入顶部 ViewZone。默认 `true` 会在第 0 行前插一块 ~33px 空白区、内容整体下移，观感为"查找框撑开一段高度"。此设置须在 monaco 升级后保留（仅悬停闪烁工作区待移除）；`ImportPreviewDialog` 的 DiffEditor 同步此设置。

## 功能

- **编辑器内搜索**：`editor.getAction('actions.find')` 触发查找框（正则、大小写敏感）。
- **粘贴自动格式化**：`onDidPaste` → `editor.action.formatDocument`。
- **JSON 校验**：非法 JSON 显示红色波浪线 + 工具栏/状态栏错误提示。
- **保存状态**：Schema 右上角状态图标；Locale 底部状态栏（见 [[concepts/自动保存|自动保存]]）。
- **双栏滚动同步**：左右编辑器按滚动比例双向同步，带 `isScrollingRef` 防反馈循环（见 [[bugs/FindWidget滚动同步|FindWidget 滚动同步]]）。
