# 导入与导出

> 语言文件的导入（JSON，带冲突预览与合并策略）与导出（ZIP 打包下载）。

## 导入（仅支持 JSON）

- **multipart**：`POST /api/projects/[id]/import`，字段 `file`（`.json`）+ `strategy` + `confirmed`。
- **语言识别**：按文件名自动识别语言标识（`zh-CN.json` → `zh-CN`）。
- **冲突预览**：首次请求（无 `confirmed`）返回 `{ preview: { addedKeys, diffKeys }, lang }`，HTTP 409；前端确认后带 `confirmed: true` 二次提交。
- **合并策略**：`overwrite`（导入数据优先）/ `skip`（已有数据优先）/ `merge`（默认，仅补不存在键）。
- **Schema 联动**：导入中出现的新键补进 Schema（空说明）。
- **数组保留**：`flattenForImport` 保留数组为叶子值（约束 5）。

### UI：ImportPreviewDialog

`Upload.Dragger` 选文件 → 首次请求拿预览 → 预览 Tab（"新增键"计数 / "差异键" Monaco DiffEditor 并排 / "完整文件预览"）→ 策略选择 → 确认提交。

## 导出（ZIP）

- `POST /api/projects/[id]/export`，body `{ languages: string[] }`（至少选一个）。
- 服务端 `archiver` 打包（zlib level 9）→ 返回 `application/zip` 流。
- 响应头：`Content-Disposition: attachment; filename="project-{id}-locales.zip"`。
- ZIP 内含 `schema.json` + 每个选中语言 `{lang}.json`。
- **UI：ExportSelectorDialog** — Checkbox 列表 + "全选"（indeterminate 态），`file-saver` 的 `saveAs()` 下载。

## 注意

- 导入/导出接口**不经过 `withApiHandler`**，手动处理错误（multipart/二进制流）。
