# 项目内译文搜索

> 在编辑器顶部搜索框按**译文内容**检索**当前项目内所有已打开语言**（`openLocales`），结果下拉呈现，点击精确定位并高亮。

## 功能定位

- 遍历 `openLocales` 的**译文值**（字符串 `includes`，不区分大小写），结果以下拉列表呈现（语言 Tag + 点分键路径 + 高亮值）。
- 点击结果 → 切换到对应语言 Tab → `revealKey` 精确定位到行 → Monaco `find` 高亮该语言内全部匹配；输入与结果**保留**，仅关闭弹出层。
- 与 Monaco 内置 Ctrl+F「编辑器内搜索」（搜键名、单栏内）**互补不重叠**。

> **命名说明**：旧文档称「全局跨语言搜索（Global Search）」有误导性——它**不是**跨项目全局搜索，而是当前项目内按译文内容查找。已更名。

## 交互状态机

- 开关：`open = searchInput 有文字 && !dismissed`。
- **关闭**（`dismissed` 置位）：鼠标离开「输入框 + 弹出层 + 16px 间隙」组合区域（`document` 级 `mousemove` 经 `classifySearchRegion` 三态归类 + 400ms 延迟）/ Esc / 点击输入框外部或焦点移出。
- **重新打开**：鼠标移回输入框 / 继续输入 / 重新聚焦（"悬停即显示"）。
- **mousemove 桥接三态**：输入框悬停 → 取消关闭 + REOPEN；弹出层悬停 → 仅取消关闭、不 REOPEN；两者之外 → 延时关闭。
- 点击结果跳转：保留输入与结果，仅 `DISMISS` 关闭弹出层。

## 防抖

- RxJS 双状态模式（镜像首页）：`searchInput`（即时显示）+ `Subject → pipe(debounceTime(300), distinctUntilChanged()) → setKeyword`（驱动 `results` 重算）。

## 实现落点

- `src/lib/monaco-reveal.ts`：纯函数 `inferKeyPath(model, lineNumber)` + `findKeyLine(model, keyPath)`。
- `src/components/project/TranslationSearchResults.tsx`：结果列表（Tag + 键路径 + SearchHighlight + 空态）。
- `src/hooks/useSearch.ts`：搜索 hook（已就绪、已测试，零改动接线）。
- `LocaleEditor`：`useImperativeHandle` 新增 `revealKey(keyPath)`。
- `page.tsx`：接线（useSearch + 防抖 Subject + Popover + 跳转 handler + 移出关闭）。

## 已识别边角

- 目标语言未 flush → `findKeyLine` 找不到行 → reveal 静默跳过，`find(keyword)` 兜底。
- 关键词含正则特殊字符 → Monaco find 按字面量处理，无需转义。
- 跳转时序：先 `setActiveLang` → `requestAnimationFrame(() => { revealKey(key); find(keyword); })` —— reveal 在前保证行先就位，find 打开会改变布局。
