# 速查面板（Cross-Reference Popover）

> 在 Schema 或译文编辑器中**选中任意键值**，浮层速查该词条在**主表 Schema（键 + 说明）**与**各语言译文**中的信息；可跳转、可复制；悬浮跟随、滚动折叠、每项目可开关。

## 触发与匹配

- **仅选中触发**：双击选词/鼠标拖选/Shift+方向键选词等非空 selection 才弹；无选中（单击/光标移动/点击空白）一律关闭。RxJS 防抖 ~200ms + 非编辑中 + 命中才弹。
- **匹配规则**（`lookupToken` 纯函数）：token 规范化（trim + 小写）后，
  - schemaHits：扁平化后 key 全路径 === token（exact）或末段 === token（segment）
  - translationHits：各语言 (lang, key, value) —— value 字符串包含 token → `value`，或 key 全路径/末段 === token → `key`
  - 排序：`key-exact > key-segment > value-exact > value-contains`；数组叶子跳过

## 状态机（referenceReducer）

`hidden ⇄ expanded ⇄ collapsed`：
- `SET_TOKEN` → expanded（新 token 先 hidden 再 expanded）
- `SCROLL`（源编辑器滚动）→ collapsed（缩成屏幕固定标记，显示键名）
- `HOVER_MARKER` → expanded（重锚定，越界钳制）
- `ENTER_POPOVER` → 取消 pending close
- `LEAVE_ALL`（离开 编辑器+弹层+标记，经桥接）→ 400ms 后 hidden
- `CLICK_OUTSIDE`（点击「源编辑器 + 浮层/标记」之外）→ 立即 hidden
- `TOKEN_MISS`（无匹配/无选中）→ hidden

## 每项目开关（Block A）

- `ProjectMeta.referenceEnabled?: boolean`（缺省视为 true，兼容旧项目）。
- `updateProjectSchema` 增加 `referenceEnabled: z.boolean().optional()`；`updateProject` 持久化到 meta.json。
- Socket：客户端 `project:settings {projectId, referenceEnabled}` → 服务端写盘 + 广播 `project:settings:updated`（last-write-wins，无冲突检测，同 locale）。
- 顶部工具栏按钮开关「速查」；关闭时浮层完全抑制。

## 架构

- **page.tsx 拥有唯一浮层实例**：编辑器只上报「当前 token + 屏幕锚点」回调；跨栏跳转/切语言由页面协调（持有两个编辑器 ref）。
- 取代旧「翻译参考」Popover（`LocaleEditor` 原浮层），两栏通用。
- 展示：命中分「Schema」「译文（按语言分组）」两段；全部命中直接渲染，弹层内滚动（`maxHeight 320 + overflowY auto`）；面板宽度 `max-content` + `min-width 300`，钳制 `max-width: min(520, 视口-2*MARGIN)`。
- antd 6 注意：`Modal`/`Drawer` 的 `maskClosable` 已弃用，须用 `mask={{ closable: ... }}`。
