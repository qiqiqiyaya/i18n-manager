# 目录结构

> 项目代码与数据目录的组织方式。数据目录运行时自动创建，按项目隔离。

## 顶层

```
project-root/
├── server.ts                  # Express 5 + Socket.IO 启动入口
├── fix-async-storage.cjs      # Next.js 16 canary AsyncLocalStorage 兼容修复
├── next.config.ts             # Next.js 配置（reactCompiler: true）
├── package.json / .env.local
└── data/                      # 运行时自动创建
    └── projects/{projectId}/
        ├── meta.json
        ├── schema.json
        └── locales/{lang}.json
```

## src/ 结构

```
src/
├── app/                       # Next.js App Router
│   ├── layout.tsx             # 根布局（Geist 字体，zh-CN lang）
│   ├── page.tsx               # 首页：项目列表（RxJS 搜索防抖 + 关键词高亮）
│   ├── globals.css            # 全局样式（Tailwind 4）
│   ├── projects/[id]/         # 编辑器页（page.tsx + layout.tsx）
│   └── api/projects/          # 全部 RESTful 接口（12 端点树）
├── components/
│   ├── json-editor/MonacoEditor.tsx   # @monaco-editor/react 封装
│   ├── project/               # SchemaEditor / LocaleEditor / LanguageTabs / 导入导出 Dialog 等
│   ├── collaboration/OnlineBadge.tsx
│   └── common/SearchHighlight.tsx
├── hooks/                     # useSocket / useProjectEditor / useSearch
├── stores/                    # editorStore / collaborationStore（Zustand）
├── lib/
│   ├── data-layer/            # io / projects / schema / locales / import-export
│   ├── validation.ts          # Zod 校验
│   ├── socket-handler.ts      # WebSocket 服务端处理
│   ├── monaco-edits.ts        # computeMinimalEdit 纯函数
│   ├── monaco-reveal.ts       # inferKeyPath / findKeyLine（译文搜索跳转）
│   ├── api-wrapper.ts         # withApiHandler HOF + CustomError
│   └── utils.ts               # flattenObject/unflattenObject 等工具
└── types/                     # api / project / schema / collaboration
```

## 数据目录

`data/projects/{projectId}/`：
- `meta.json` — 项目信息（标题、描述、时间戳）
- `schema.json` — 主表（嵌套 JSON，键→说明/子对象）
- `locales/{lang}.json` — 各语言译文（嵌套，与 Schema 一致）

所有文件 UTF-8 编码；读写走原子写入（见 [[数据层|数据层]]）。
