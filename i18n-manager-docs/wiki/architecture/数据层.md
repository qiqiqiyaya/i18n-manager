# 数据层

> `src/lib/data-layer/` 是服务端数据访问层：文件 I/O 原语、项目/Schema/Locale 管理、导入导出、并发安全（原子写 + 锁）。

## 模块划分

| 模块 | 职责 |
|------|------|
| `index.ts` | 统一导出入口 |
| `io.ts` | 文件 I/O 原语：`DATA_DIR`、`getProjectDir`、`ensureProjectDir`、`atomicWriteJson`、`readJson` |
| `projects.ts` | 项目 CRUD：`getAllProjects`/`searchProjects`/`getProjectById`/`createProject`/`updateProject`/`deleteProject`/`isProjectExists` |
| `schema.ts` | Schema 管理 + 增量更新 + 键变更同步到所有 locale + Socket.IO 广播；模块级 `lastSchemaTimestamps`（HTTP 冲突检测） |
| `locales.ts` | Locale 管理 + 增量更新 + 最后语言保护 |
| `import-export.ts` | `previewImport`/`executeImport`/`getExportData` + `flattenForImport`（数组保留） |

## 原子写入（io.ts）

- `atomicWriteJson(path, data)`：`proper-lockfile` 锁定目标文件路径（目标不存在先建空 JSON）→ 写 `.tmp` → `fs.move` 替换 → 释放锁。
- 重试 5 次、50–200ms 间隔；是并发安全的主要保障（见 [[concepts/并发与冲突处理|并发与冲突处理]]）。

## Schema 模块要点

- `updateSchema` / `updateSchemaIncremental`（扁平路径增量，含时间戳冲突检测 → 409）。
- `syncSchemaChangesToLocales`：Schema 键变更同步到所有语言文件（磁盘）并广播 `locale:synced`/`schema:updated`。
- **HTTP 与 Socket.IO 共用冲突检测**：避免"广播被拒但仍写盘"的不一致。

## Locale 模块要点

- CRUD + `updateLocaleIncremental`（扁平路径增量）。
- **最后语言保护**：删除最后一个语言返回 409。

## 共享 IO 实例

`setIO`/`getIO` 经 `globalThis` 共享 Socket.IO 实例，跨 Next.js 打包边界供 data-layer 广播使用。
