# 技术栈与依赖

> 全栈 Next.js 16（App Router, canary）+ Express 5 自定义服务器 + Socket.IO 实时协作 + 本地 JSON 持久化。零外部服务。

## 前端依赖

| 类别 | 选型 | 版本 | 说明 |
|------|------|------|------|
| 核心框架 | Next.js | `16.3.0-preview`（canary） | App Router，自定义 `server.ts` |
| UI 库 | Ant Design | `6.5.0`+ | 配套 `@ant-design/icons` 6.x |
| JSON 编辑器 | @monaco-editor/react | `4.7.0`+ | Monaco + DiffEditor |
| 状态管理 | Zustand | `5.0.0`+ | editorStore / collaborationStore |
| HTTP | axios | `1.18.0`+ | 统一拦截器处理异常 |
| WebSocket | socket.io-client | `4.8.0`+ | 自动重连 |
| 响应式 | RxJS | `7.8.0`+ | debounce/distinctUntilChanged |
| 下载 | file-saver | `2.0.5` | ZIP 下载触发 |
| CSS | Tailwind CSS | `4.x` | 全局样式 |

## 后端依赖

| 类别 | 选型 | 版本 | 说明 |
|------|------|------|------|
| 运行时 | Node.js | **22 LTS**（打包用 `v22.14.0` win-x64） | ⚠️ 见 C2 矛盾 |
| 自定义服务器 | Express | `5.2.0`+ | 包装 Next.js，挂载 Socket.IO |
| 实时通信 | Socket.IO | `4.8.0`+ | 房间广播、心跳 |
| 文件操作 | fs-extra | `11.3.0`+ | 原子写入等 |
| 并发锁 | proper-lockfile | `4.1.2` | 防止文件并发写冲突 |
| 数据校验 | zod | `4.4.0`+ | 校验 API 输入 |
| 日志 | pino | `10.3.0`+ | ⚠️ 未使用（候选移除） |
| ZIP 打包 | archiver | `8.0.0`+ | v7+ 为 ESM only，用 `ZipArchive` 命名导入 |
| TS 执行 | tsx | `4.22.0`+ | 直接运行 `server.ts` |

> **未使用依赖**：`pino`（未接入源码）、`react-highlight-words`（`SearchHighlight.tsx` 正则 + `<mark>` 自实现）——均候选移除。

## 环境变量

| 变量 | 必需 | 默认值 | 说明 |
|------|------|--------|------|
| `NEXT_PUBLIC_AUTO_SAVE_DEBOUNCE` | 否 | `1000` | 自动保存防抖延迟（ms） |
| `NEXT_PUBLIC_WS_URL` | 否 | `http://localhost:3000` | 前端 Socket.IO 地址（构建时烘焙） |
| `DATA_DIR` | 否 | `./data` | 数据持久化根目录 |
| `PORT` | 否 | `3000` | HTTP/WebSocket 监听端口 |
