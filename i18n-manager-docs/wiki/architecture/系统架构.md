# 系统架构概览

> 单进程拓扑：Express 5 包装 Next.js，同一 HTTP server 挂载 Socket.IO，HTTP 与 WebSocket 同端口（默认 3000），数据持久化到本地 JSON 文件。

## 概述

- **单进程**：`server.ts`（经 `tsx` 运行）同时处理 HTTP 与 WebSocket。Socket.IO 路径 `/socket.io` 由 HTTP server 自处理，其余请求转交 Next.js。
- **兼容层**：`fix-async-storage.cjs` 通过 `--require` 在启动前注入 `globalThis.AsyncLocalStorage`，修复 Next.js 16 canary 兼容性。
- **启动命令**：`node --require ./fix-async-storage.cjs --import tsx server.ts`。

## 分层图

```
Browser（React 19 + Ant Design 6 + Monaco + Socket.IO Client + RxJS）
   │  HTTP/JSON API                    │ WebSocket
   ▼                                   ▼
Express 5 + Next.js Server（server.ts）
   ├── Socket.IO：schema:updated/schema:save/locale:save/online_count/…
   ├── Next.js App Router：页面 + API 路由（withApiHandler HOF）
   └── Data Layer（src/lib/data-layer/：io/projects/schema/locales/import-export）
   ▼
本地文件系统（DATA_DIR/projects/{projectId}/：meta.json + schema.json + locales/{lang}.json）
```

## 6 个关键架构决策

1. **无用户、无数据库**：数据全局共享；本地 JSON 文件持久化；原"客户端 IP 作为操作者标识"已被无身份识别替代。
2. **Socket.IO 实时协作**：按项目房间隔离（`room:project-{projectId}`）。⚠️ 原含键级锁定（30s 超时 `LOCK_TIMEOUT`）——**已移除**，见 [[concepts/并发与冲突处理|并发与冲突处理]]。
3. **编辑器 Monaco only**：左右双栏均用 `@monaco-editor/react`；导入预览用 `DiffEditor`。
4. **自动保存管道**：RxJS debounce → 哈希去重 → Socket.IO 持久化 → 原子写 → 广播。
5. **数据流方向**：`onChange → Subject → debounce → parse → store → Socket.IO → 服务端原子写`。
6. **Schema 变更传播**：计算增删/重命名 → 客户端 `applyLocaleSync` + 服务端 `syncSchemaChangesToLocales` → 广播 `locale:synced`/`schema:updated`。

> [!warning] ⚠️ 文档矛盾
> `[[raw/CODEMAPS/architecture.md|architecture.md]]` 的系统图仍含 `lock`/`unlock` 事件与键级锁（30s 超时）。
> **权威状态**：键级锁定已于 2026-08-09 移除；当前协作协议不含 `lock`/`unlock`。
