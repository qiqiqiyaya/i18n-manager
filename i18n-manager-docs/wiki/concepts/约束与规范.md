# 设计约束与编码规范

> 全项目横切的硬性约束与编码约定，多数源自 `i18nManager.md` §6「AI 编码强制性约束」与父仓库 `CLAUDE.md`。任何实现不得违背。

## 核心约束

- **编辑器强制 `@monaco-editor/react`**：Schema 与译文编辑均使用 Monaco（JSON 文本模式）；**禁止**用 Ant Design Table/Tree 替代。导入预览用 Monaco `DiffEditor`。
- **无用户系统 / 无身份识别**：数据全局共享；既不用 IP 也不用 cookie/session（键级锁定时代"按 IP 区分操作者"的说法已作废）。
- **RxJS 防抖/去重**：涉及 debounce、distinctUntilChanged 等响应式操作必须用 RxJS `Observable` 管道，**禁用**原生 `setTimeout`/`clearTimeout`。
- **数组保留**：`flattenObject`/`flattenForImport` 遇数组原样保留为叶子值，不展开、不抛错。
- **最后语言保护**：删除语言时若为项目最后一个语言返回 409 拒绝。
- **Socket.IO 持久化优先**：Schema/Locale 保存经 `schema:save`/`locale:save` 直写磁盘；HTTP PATCH 增量接口作为备用。
- **原子写入**：所有文件写入走 `proper-lockfile` 互斥 + `.tmp` 替换（`data-layer/io.ts`）。
- **接收端最小编辑**：`MonacoEditor.setValue` 走 `computeMinimalEdit` + `model.pushEditOperations`，**不用 `editor.setValue`**（后者整体替换缓冲区、清空 undo/redo 栈、重置折叠状态）。**不要手动保存/恢复光标位置**——光标由 Monaco 依编辑范围自动调整（决策 11）。

> `[[raw/CODEMAPS/frontend.md|frontend.md]]` 仍描述 `MonacoEditor.tsx` "Handles value prop sync with cursor/scroll position preservation" 与 `fromUserRef` 标志。
> **权威状态**：父仓库 `CLAUDE.md` 决策 11 —— 手动光标恢复为补偿 `setValue` 破坏性的旧代码，**已移除**；现用最小编辑保留 undo/折叠，光标自动调整。

## 编码规范

- **不可变数据**：创建新对象，绝不就地修改（immutability）。
- **KISS / DRY / YAGNI**：最简单可行方案；不重复；不做投机性扩展。
- **尺寸限制**：函数 <50 行，文件 <800 行，嵌套 ≤4 层。
- **错误处理**：显式处理每层错误；UI 层给用户友好信息；服务端记详细上下文；不静默吞错。
- **输入校验**：系统边界用 Zod 校验（`src/lib/validation.ts`）。
- **提交规范**：Conventional Commits（`feat/fix/refactor/docs/test/chore/perf/ci`）。
- **测试**：TDD + AAA，目标覆盖率 ≥80%。
