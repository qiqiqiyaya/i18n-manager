# 自动保存

> 编辑器变更无需手动保存：防抖 + 哈希去重 + 增量/全量持久化，经 Socket.IO 直写磁盘，状态实时反馈。

## 概述

用户编辑 Schema 或译文后不立即保存。系统以 RxJS 管道做**防抖**（默认 1000ms，`NEXT_PUBLIC_AUTO_SAVE_DEBOUNCE`），停止输入后才触发；触发前做**内容哈希去重**（`JSON.stringify` 比对，无变化则跳过）；保存走 Socket.IO 事件（`schema:save`/`locale:save`）直写磁盘，HTTP PATCH 增量接口为备用路径。

## 要点

- **防抖用 RxJS，禁用原生 setTimeout**：`Subject` → `pipe(debounceTime(1000), distinctUntilChanged())` → 解析/保存（项目约束 7）。
- **去重**：触发保存前比较当前数据与上次成功保存的数据（内容哈希），完全一致则跳过，避免光标移动等误触发。
- **保存主路径**：编辑器解析成功后发送 `schema:save`/`locale:save`，服务端 `updateSchema`/`updateLocale` 直写嵌套对象；回执经 `schema:saved`/`locale:saved` 返回。
- **备用路径（HTTP PATCH）**：`/schema/keys`、`/locales/[lang]/keys` 增量接口，基于扁平化路径发送 `{ updates, deletes, timestamp? }`，服务端读盘 → 应用增量 → 原子写。
- **保存状态机**：`editorStore.saveStatus` = `idle | dirty | saving | saved | error`；`saveError` 存错误信息。
- **UI 反馈**：Schema 工具栏右上角状态图标，Locale 底部状态栏；"保存中"至少显示 800ms（避免一闪而过），"已保存"2s 后回到 idle。
- **关闭提示**：`beforeunload` 监听，`isDirty === true` 时弹出"有未保存更改，是否离开？"。

## 数据流

```
Monaco onChange → Subject.next(value)
  → debounceTime(1s) + distinctUntilChanged
  → JSON.parse → 哈希对比 → 有变化？
    → 更新 Zustand（isDirty = true）
    → sendSchemaSave / sendLocaleSave（Socket.IO）
    → 服务端原子写 → 广播到房间
```
