# 扁平化与还原算法

> 在嵌套 JSON 与点分隔扁平键之间转换的核心算法，是导入/导出、搜索、增量传输、WebSocket `keyPath` 的数据基础。

## 概述

使用 `.` 作为分隔符，把嵌套对象转成扁平键值对：`{ "emp": { "name": "姓名" } }` → `{ "emp.name": "姓名" }`。还原（`unflattenObject`）把 `{ "emp.name": "张三", "emp.age": 30 }` 还原为 `{ "emp": { "name": "张三", "age": 30 } }`；若路径冲突，以**最深层级**为准并记录警告日志。

## 要点

- **数组保留为叶子**：`flattenObject` 与 `import-export.ts` 的 `flattenForImport` 遇到数组时**原样保留该数组**作为叶子值，不展开为点分隔键、不抛错（commit `7e4e619` 修复）。
- **空嵌套对象**：`flattenObject` 遇到 `{}` 保留为叶子（值为空字符串 `""`），如 `{ "yiku": {} }` → `{ "yiku": "" }`；`deepMergeTemplate` 还原时确保空嵌套对象保持为 `{}` 而非 `""`。
- **遍历顺序**：深度优先，按键名字典序排列。

> `[[raw/CODEMAPS/data.md|data.md]]` 的转换管道说明仍写「flattenObject … throws on arrays」。
> **权威状态**：`[[raw/i18nManager.md|i18nManager.md]]` §6.3 —— 数组保留为叶子，不抛错（commit `7e4e619`）。`flattenForImport` 同样保留数组。

## 工具函数清单（src/lib/utils.ts）

| 函数 | 作用 |
|------|------|
| `flattenObject` | 嵌套对象 → 扁平键值对（数组保留） |
| `unflattenObject` | 扁平键值对 → 嵌套对象 |
| `setNestedValue` | 按点分隔路径设置嵌套值 |
| `getLeafPaths` | 收集所有叶子路径（空嵌套对象视为叶子） |
| `createNestedFromPaths` | 由叶子路径重建嵌套对象（叶子值 `""`） |
| `findMissingPaths` | 递归对比找出缺失的叶子路径 |
| `emptyTranslationsFromSchema` | 按 Schema 生成空翻译对象 |
| `hasNestedPath` | 检测点分隔路径是否存在 |
| `deepClone` | 深拷贝（JSON.parse/stringify） |
| `deepMergeTemplate` | 递归深度合并（template 覆盖，保留已有值，空对象保持 `{}`） |

## 应用场景

- 导入/导出预览的冲突检测
- 搜索关键词匹配（键路径）
- 增量传输中的 `updates`/`deletes` 路径标识
- WebSocket 广播的 `keyPath` 字段
- Schema 重复键检测中的路径构造
