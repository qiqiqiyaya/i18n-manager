# 打包分发

> 将应用打包为独立运行包：**Portable Node.js + 启动脚本**，无需用户安装 Node.js，双击启动，支持注册 Windows Service 开机自启。

## 方案概述

1. 下载 Node.js 便携版（绿色版 zip）
2. 构建 Next.js 生产版本
3. 与应用文件捆绑
4. 通过 `.bat` / `.ps1` 脚本启动

## 打包命令

```bash
npm run package         # 完整打包（构建 + 下载 Node.js + 打包）
npm run package:fast    # 仅打包（已有构建产物，跳过构建）
npm run package:no-dl   # 仅打包（跳过 Node.js 下载，需手动放置 node/）
```

`scripts/package.js` 支持参数：`--platform=win-x64`（默认）、`--no-build`、`--no-download`。

## 输出结构（pkg/）

```
pkg/
├── node/                # 便携版 Node.js（自动下载）
├── app/                 # .next / server.ts / fix-async-storage.cjs / next.config.ts / package.json / node_modules
├── data/projects/       # 运行时数据（自动创建）
├── start.bat            # 普通启动（双击）
├── start-silent.bat     # 静默启动（无控制台窗口）
├── start.ps1            # PowerShell 启动
├── service.ps1          # Windows Service 管理
└── README.txt
```

## 启动与 Windows Service

**普通启动**：双击 `start.bat` 或 `.\pkg\start.ps1`，访问 `http://localhost:3000`。

**Windows Service**（管理员 PowerShell）：
```powershell
.\pkg\service.ps1 install | stop | start | status | uninstall
```

- 注册：`New-Service`，`StartupType Automatic`。
- 自动重启：`sc.exe failure "i18n-manager" reset=86400 actions=restart/60000/restart/120000/restart/300000`。

**实际启动命令等价于**：
```bash
node --require ./fix-async-storage.cjs --import node_modules/tsx/dist/esm/index.mjs server.ts
```
环境变量：`DATA_DIR=pkg/data`、`PORT=3000`。Node `v22.14.0` win-x64。

## 风险与优化方向

| 风险 | 缓解 |
|------|------|
| `proper-lockfile` 文件锁行为 | 测试验证 |
| `tsx` 运行时性能略低 | 可预编译 `server.ts` 为 `.js` |
| 分发文件较大（~50MB + Node ~40MB） | UPX 压缩 Node 二进制 |
| Next.js 16 canary 更新兼容 | 锁定版本，测试后再更新 |

优化方向：C# 启动器（~10KB .exe）、Inno Setup / NSIS 安装程序、UPX、esbuild/tsc 预编译、自动更新、托盘图标。
