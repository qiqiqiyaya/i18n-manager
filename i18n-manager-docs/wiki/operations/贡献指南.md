# 贡献指南

> 面向 i18n Manager 贡献者的开发指南：环境准备、脚本、测试约定、代码风格与提交规范。

## 环境准备

- 前置：Node 20+（⚠️ 见 C2 矛盾）、npm、ES2022 运行环境。
- 安装：`npm install` → `cp .env.example .env.local`（可选）→ `npm run start:server`。
- ⚠️ `start:server` 实际执行 `node --require ./fix-async-storage.cjs --import tsx server.ts`，`fix-async-storage.cjs` 不可删除。
- 命令表/环境变量表/API 参考由源码自动生成（`AUTO-GENERATED` 区块），**勿手动编辑**。

## 可用脚本

| 命令 | 说明 |
|------|------|
| `npm run dev` | Next.js 开发服务器（仅页面，不含 Express/Socket.IO） |
| `npm run build` | 生产构建 |
| `npm run start` | 生产启动 Next.js（不含 Express/Socket.IO） |
| `npm run start:server` | 完整启动（推荐） |
| `npm run lint` | ESLint |
| `npx tsc --noEmit` | TypeScript 类型检查 |
| `npm test` / `test:watch` / `test:coverage` | Vitest 测试（⚠️ 见 C5 矛盾） |

## 测试约定

- **TDD**（RED → GREEN → REFACTOR）+ **AAA**（Arrange-Act-Assert）结构；目标覆盖率 ≥80%。
- 优先测试：`src/lib/data-layer/`、`src/lib/utils.ts`、`src/lib/validation.ts`、`src/lib/socket-handler.ts`。
- 当前测试栈：**Vitest 4 + jsdom + @testing-library/react**，7 文件 / 172 测试（`i18nManager.md` §6.7.1）。

## 代码风格

- 不可变数据；KISS/DRY/YAGNI；函数 <50 行、文件 <800 行。
- 防抖/节流/去重用 **RxJS**，禁用原生 `setTimeout`/`clearTimeout`。
- 编辑器必须用 `@monaco-editor/react`。
- 提交前运行 `npm run lint` + `npx tsc --noEmit`。

## 提交与 PR

- **Conventional Commits**：`<type>: <description>`；类型 `feat/fix/refactor/docs/test/chore/perf/ci`。
- **PR 清单**：lint 通过 / `tsc --noEmit` 无错 / build 成功 / 新功能含测试（≥80%）/ 无硬编码密钥、无 `console.log` / 分支同步无冲突。
