# 项目（Project）

> 平台最顶层的管理单元：一个项目承载一组多语言翻译条目，数据落在 `data/projects/{projectId}/` 目录。

## 概述

项目通过 `id`（UUID，`crypto.randomUUID()` 生成）唯一标识。翻译信息经 `projectId` 与项目**弱关联**（仅存储 ID，无外键约束）。项目本身不存语言数据，只存元信息（`meta.json`）；[[Schema主表|Schema]] 与 [[语言文件|语言文件]] 挂在项目目录下。

## 字段（meta.json）

| 字段 | 必填 | 约束 |
|------|------|------|
| `id` | ✅ | UUID |
| `title` | ✅ | 1~50 字符 |
| `description` | ❌ | ≤200 字符 |
| `createdAt` / `updatedAt` | ✅ | ISO-8601 |

## 要点

- **CRUD 接口**：创建、编辑、删除、查询（详见 [[architecture/RESTful-API|RESTful API 契约]]）。
- **模糊搜索**：对 `title`/`description` 做 `includes` 匹配（不区分大小写）；首页全量缓存 + 本地过滤 + RxJS 防抖 300ms。
- **数据目录**：`data/projects/{projectId}/`，运行时自动创建，删除项目 = 递归删除目录。
- **无用户系统**：数据全局共享，无身份识别（非 IP/cookie/session）。在线人数按 Socket.IO 房间**连接数**统计，同浏览器多 tab 各计一次（见 [[concepts/并发与冲突处理|并发与冲突处理]]）。
- 新项目初始化：写 `meta.json` + 空 `schema.json`，`locales/` 目录就绪。
