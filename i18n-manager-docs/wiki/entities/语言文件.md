# 语言文件（Locale）

> 项目内某一语言的完整译文，存于 `locales/{lang}.json`，嵌套结构与 [[Schema主表|Schema]] 一致，叶子节点填实际译文。

## 概述

一个项目可包含多个语言版本（如 `en-US`、`zh-CN`、`ja-JP`）。每个语言一个 JSON 文件，结构由 Schema 派生。语言标识用正则 `/^[a-zA-Z0-9_-]+$/` 校验，长度 2~20 字符。`meta.json` 不保存语言清单，语言列表由 `locales/` 目录文件枚举。

## 要点

- **空译文生成**：添加新语言时，用 `emptyTranslationsFromSchema`/`createNestedFromPaths` 按当前 Schema 结构生成空译文（叶子为空字符串 `""`，空嵌套对象保持 `{}`）。
- **Tab 管理**：右栏语言 Tab 支持打开/关闭/添加；**至少保留一个 Tab**（关闭操作不删除文件）。"+"按钮下拉列出未打开语言 + "添加新语言"入口（详见 [[features/编辑器|编辑器]]）。
- **最后语言保护**：删除项目最后一个语言返回 409 拒绝（`DELETE /locales/[lang]`）。
- **Schema 键变更同步**：Schema 增/删/改名时，所有语言文件同步增补/移除/迁移对应键（见 [[Schema主表|Schema 主表]]）。
- **搜索范围**：项目内译文搜索仅遍历**已打开**的语言（`openLocales`），见 [[features/项目内译文搜索|项目内译文搜索]]。
